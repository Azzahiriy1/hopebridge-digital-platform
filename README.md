# HopeBridge Digital Platform — MoneyBridge MVP

A bilingual (English/Hausa), mobile-friendly prototype for the Ali Azzahiriy HopeBridge Youth Initiative.

## What is included
- About / mission pages for the initiative
- A simple small-business cashbook (income and expenses)
- A savings target field
- Basic financial safety and money-management learning cards
- English/Hausa language toggle
- Initiative logo supplied by the founder

## Important prototype limits
- This is a front-end demonstration, not a production financial service.
- Records are stored only in the current browser/device using localStorage. Clearing browser data or changing devices may remove them.
- No user accounts, server database, payments, beneficiary case-management, identity documents, BVN, NIN or bank details are collected.
- Do not enter sensitive personal information.
- Before real deployment, add a privacy policy, security review, backups, consent process and appropriate governance.

## Preview
Open `index.html` in a browser. Keep the `assets` folder next to it.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and the entire `assets` folder.
3. In repository Settings → Pages, choose Deploy from a branch, select `main` and `/root`, then Save.
4. Wait for GitHub Pages to provide the public site address.

## USPF challenge preparation
This prototype is a starting point for a Financial Inclusion concept. The team must still validate a real community problem, test with intended users, document feedback, and explain how the tool responds to the official Financial Inclusion problem statement. Do not claim that the prototype is already proven or that the team has users/partners unless that is true.
